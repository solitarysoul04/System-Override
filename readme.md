# System Override: Lunar Orbit 🌙

A web-based zine on hardware struggles, astrophysics and human emotion.
This website was created for Hack Club Boba Bash in Delhi.

## 📖 About the Project

This is a 2-page interactive story. A mix of my actual hardware struggles (unreliable ESP32s, OpenCV warnings), a true story written in a Hinglish poem, with a dollop of code thrown in which makes all the emotions presentable.

In place of a conventional, slick portfolio website, I created a machine that’s not quite understood how to connect with humans.

**The Narrative:**

*   **Phase 1: (Crash)** You're given sort of an `index.html`—a raw terminal boot sequence. It documents the usual embedded functions of hardware, but ultimately crashes due to a "logic fault" in an attempt to compile a human emotion.
*   **Phase 2: (Override)** If logic fails, click on the critical error and the system will jump over the failed logic and move to `override.html`. This page strips the UI elements and styling away, leaves behind the text and instead displays a bare document with my sister's moon photography and my poetry on relationships from astrophysics (orbits, event horizons, latency).

## 🛠️ The Tech Stack

The entire project has been created using HTML and CSS.
